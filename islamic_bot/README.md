# 🕌 بوت إدارة القنوات الدينية - Islamic Channel Bot

بوت تليجرام متكامل ومصمم خصيصاً لإدارة القنوات الدينية ونشر المحتوى الإسلامي تلقائياً.

## ✨ المميزات الرئيسية

### 📿 الأذكار التلقائية
- نشر أذكار الصباح تلقائياً (6:00 صباحاً)
- نشر أذكار المساء تلقائياً (6:00 مساءً)
- أذكار النوم قبل النوم
- تسبيحات دورية طوال اليوم

### 📖 المحتوى اليومي
- آية قرآنية يومية مختارة
- حديث شريف يومي مع المصدر
- محتوى متنوع من القرآن والسنة

### 📊 الإحصائيات والتحكم
- إحصائيات مفصلة لكل قناة
- تقارير عن عدد المنشورات
- تحكم كامل في الإعدادات
- تفعيل/تعطيل كل ميزة على حدة

### 🎯 سهولة الاستخدام
- واجهة عربية بالكامل
- أزرار تفاعلية سهلة
- أوامر بسيطة وواضحة
- دعم متعدد القنوات

## 🚀 التثبيت

### 1. استنساخ المشروع
```bash
cd /workspace/islamic_bot
```

### 2. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 3. إعداد ملف البيئة
أنشئ ملف `.env` في مجلد المشروع وأضف التالي:
```env
BOT_TOKEN=your_bot_token_here
ADMIN_IDS=123456789,987654321
DATABASE_PATH=islamic_channels.db
```

### 4. الحصول على توكن البوت
1. افتح Telegram وابحث عن @BotFather
2. أرسل الأمر `/newbot`
3. اتبع التعليمات للحصول على التوكن
4. انسخ التوكن وضعه في ملف `.env`

## 📱 التشغيل

```bash
cd /workspace/islamic_bot
python bot.py
```

## 📋 الأوامر المتاحة

### أوامر الإدارة
| الأمر | الوصف |
|-------|-------|
| `/start` | رسالة الترحيب والقائمة الرئيسية |
| `/help` | عرض دليل الاستخدام |
| `/add_channel` | إضافة قناة جديدة |
| `/my_channels` | عرض قنواتك المسجلة |

### أوامر النشر اليدوي
| الأمر | الوصف |
|-------|-------|
| `/publish_adkar` | نشر الأذكار الآن |
| `/publish_verse` | نشر آية قرآنية |
| `/publish_hadith` | نشر حديث شريف |
| `/publish_tasbih` | نشر تسبيحة |

### أوامر التحكم
| الأمر | الوصف |
|-------|-------|
| `/stats` | عرض إحصائيات القناة |
| `/settings` | إعدادات القناة |

## ⚙️ الإعدادات

يمكنك التحكم في كل ميزة من خلال القائمة التفاعلية:
- ✅ تفعيل/تعطيل أذكار الصباح والمساء
- ✅ تفعيل/تعطيل الآيات اليومية
- ✅ تفعيل/تعطيل الأحاديث اليومية
- ✅ تفعيل/تعطيل التسبيحات الدورية

## 🗄️ قاعدة البيانات

يستخدم البوت SQLite لتخزين:
- معلومات القنوات المسجلة
- سجل المنشورات
- الإحصائيات اليومية
- المهام المجدولة

## 🔧 التطوير

### هيكل المشروع
```
islamic_bot/
├── config.py          # إعدادات البوت والمحتوى
├── database.py        # إدارة قاعدة البيانات
├── bot.py            # الكود الرئيسي للبوت
├── requirements.txt   # المكتبات المطلوبة
└── .env              # متغيرات البيئة
```

### إضافة محتوى جديد

لتعديل المحتوى الإسلامي، عدل ملف `config.py`:

```python
class IslamicContent:
    MORNING_ADKAR = [
        "ذكر جديد هنا",
        # ...
    ]
    
    QURAN_VERSES = [
        {"verse": "الآية", "surah": "السورة: الرقم"},
        # ...
    ]
```

## 📝 ملاحظات مهمة

1. **صلاحيات البوت**: يجب إضافة البوت كـ **مشرف** في القناة لنشر المحتوى
2. **التوقيت**: جميع الأوقات مضبوطة بالتوقيت العالمي (UTC)
3. **الحدود**: يمكن لكل مستخدم تسجيل حتى 10 قنوات كحد أقصى
4. **الصيانة**: ينظف البوت البيانات القديمة تلقائياً بعد 30 يوم
