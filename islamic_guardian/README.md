# 🕌 بوت الحارس الإسلامي (Islamic Channel Guardian)

<div dir="rtl">

## نظرة عامة

بوت تليجرام احترافي لإدارة القنوات الدينية ونشر المحتوى الإسلامي الموثق تلقائياً.

### ⭐ المبدأ الأساسي

> **"لا نؤلف المحتوى الديني، بل نتحقق منه وننشر الموثوق منه"**

---

## ✨ المميزات

### 📿 المحتوى التلقائي
- **أذكار الصباح** - نشر تلقائي يومياً (6:00 صباحاً)
- **أذكار المساء** - نشر تلقائي يومياً (6:00 مساءً)
- **آية يومية** - آية قرآنية مختارة يومياً (8:00 صباحاً)
- **حديث شريف** - حديث نبوي صحيح يومي (12:00 ظهراً)
- **أدعية مأثورة** - أدعية صحيحة (3:00 عصراً)
- **تسبيحات** - كل ساعتين
- **استغفار** - كل 3 ساعات

### 🛡️ نظام الأمان والتحقق

```
سلسلة التحقق الصارمة:
1. ✅ Database Verification → التحقق من قاعدة المحتوى الموثوق
2. ✅ Source Check → التحقق من المصدر
3. ✅ Content Integrity Check → التحقق من سلامة المحتوى
4. ✅ Duplicate Check → منع التكرار
5. ✅ Safety Check → التحقق الأمني
6. ✅ Publish → النشر (فقط إذا نجحت جميع الخطوات)
```

### 🔒 الحماية
- منع المحتوى غير الموثق
- منع المحتوى المولد بالذكاء الاصطناعي
- منع التكرار خلال 24 ساعة
- سجل تدقيق كامل لجميع العمليات
- حظر مؤقت للمستخدمين المشبوهين
- **إيقاف طوارئ فوري** 🚨

### 📊 الإدارة
- إدارة عدد غير محدود من القنوات
- إعدادات مستقلة لكل قناة
- إحصائيات مفصلة
- لوحة تحكم شاملة
- مراجعة بشرية للمحتوى الجديد

## 🚀 التثبيت والتشغيل

### 1️⃣ المتطلبات الأساسية
- Python 3.7 أو أحدث
- توكن بوت من @BotFather

### 2️⃣ تثبيت المكتبات

```bash
cd islamic_guardian
pip install -r requirements.txt
```

### 3️⃣ إعداد متغيرات البيئة

انسخ ملف `.env.example` إلى `.env`:

```bash
cp .env.example .env
```

ثم عدل ملف `.env` وأضف توكن البوت:

```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
ADMIN_IDS=123456789,987654321
```

### 4️⃣ تشغيل البوت

```bash
python bot.py
```

## ⚙️ التخصيص

### تعديل أوقات النشر

في ملف `config.py`، عدل فئة `DefaultSchedule`:

```python
@dataclass
class DefaultSchedule:
    ADKAR_MORNING: time = time(6, 0)   # 6:00 صباحاً
    ADKAR_EVENING: time = time(18, 0)  # 6:00 مساءً
    VERSE_DAILY: time = time(8, 0)     # 8:00 صباحاً
    HADITH_DAILY: time = time(12, 0)   # 12:00 ظهراً
```

### إضافة محتوى موثق جديد

في ملف `config.py`، أضف إلى قاموس `VERIFIED_CONTENT`:

```python
VERIFIED_CONTENT = {
    "adkar_morning": [
        {
            "text": "الذكر المراد إضافته",
            "source": "صحيح البخاري",  # مصدر موثق فقط
            "reference": "البخاري 123",
            "count": 1
        }
    ],
    # ... باقي الأنواع
}
```

### المصادر المقبولة

في ملف `config.py`، قائمة `ACCEPTED_SOURCES`:

```python
ACCEPTED_SOURCES = [
    "القرآن الكريم",
    "صحيح البخاري",
    "صحيح مسلم",
    "صحيح الترمذي",
    "صحيح أبي داود",
    "صحيح النسائي",
    "صحيح ابن ماجه",
    # ... المزيد
]
```

## 📊 قاعدة البيانات

يستخدم البوت SQLite مع الجداول التالية:

- `channels` - القنوات المضافة
- `channel_settings` - إعدادات كل قناة
- `publish_log` - سجل النشر
- `audit_log` - سجل التدقيق الأمني
- `pending_content` - المحتوى قيد المراجعة
- `temp_bans` - الحظر المؤقت
- `emergency_status` - حالة الطوارئ

---

## 🔐 الأمان

### نظام التحقق من المحتوى

1. **التحقق من قاعدة البيانات**: يجب أن يكون المحتوى موجوداً في القاعدة الموثوقة
2. **التحقق من المصدر**: يجب أن يكون المصدر من القائمة المقبولة
3. **سلامة المحتوى**: كشف المحتوى المولد بالذكاء الاصطناعي
4. **منع التكرار**: عدم نشر نفس المحتوى خلال 24 ساعة
5. **التحقق الأمني**: كشف الكلمات المرفوضة والروابط المشبوهة

### سجل التدقيق

جميع العمليات مسجلة في `audit_log`:
- إضافة/حذف القنوات
- تغيير الإعدادات
- عمليات النشر
- أوامر الطوارئ

---

## 🚨 إيقاف الطوارئ

يمكن إيقاف جميع عمليات النشر فوراً باستخدام:

1. الأمر `/emergency_stop` من البوت
2. تحديث حالة الطوارئ في قاعدة البيانات مباشرة

للاستئناف: `/resume`

---

## 📈 الإحصائيات

احصل على إحصائيات شاملة باستخدام `/stats`:

- عدد القنوات (الإجمالي والنشطة)
- عدد المنشورات (الناجحة والفاشلة)
- المحتوى قيد المراجعة
- المستخدمون المحظورون

---

## 💡 نصائح مهمة

1. **إضافة البوت كمشرف**: يجب إضافة البوت كـ **مشرف** في القناة للنشر
2. **معرف القناة**: استخدم @RawDataBot لمعرفة معرف القناة
3. **النسخ الاحتياطي**: احتفظ بنسخة من ملف `data/guardian.db`
4. **السجلات**: راجع `logs/error.log` عند حدوث مشاكل
5. **المحتوى**: لا تضف أي محتوى غير موثق

---

## ❗ تحذيرات هامة

> ⚠️ **تحذير 1**: لا تقم أبداً بإضافة محتوى ديني غير موثق

> ⚠️ **تحذير 2**: البوت يرفض أي محتوى مولد بالذكاء الاصطناعي

> ⚠️ **تحذير 3**: تحقق من صحة التوكن قبل التشغيل

> ⚠️ **تحذير 4**: احتفظ بنسخة احتياطية من قاعدة البيانات

## 🛠️ استكشاف الأخطاء

### البوت لا يعمل
```bash
# تحقق من التوكن
echo $BOT_TOKEN

# تحقق من السجلات
cat logs/error.log
```

### البوت لا ينشر في القناة
1. تأكد من إضافة البوت كـ **مشرف**
2. تحقق من حالة القناة: `/my_channels`
3. راجع سجل النشر

### خطأ في قاعدة البيانات
```bash
# احذف قاعدة البيانات التالفة
rm data/guardian.db

# أعد تشغيل البوت لإنشاء قاعدة جديدة
python bot.py
```
